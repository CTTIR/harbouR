# Check a base for problems before writing it

Reports structural issues that would make SeaTable reject the file, or
that indicate the base was built incorrectly in R.

## Usage

``` r
hb_validate_dtable(x, ...)
```

## Arguments

- x:

  A `harbour_dtable`.

- ...:

  These dots are for future extensions and must be empty.

## Value

A tibble with columns `location` (chr), `problem` (chr) and `severity`
(chr, `"error"` or `"warning"`). Zero rows means the base is
well-formed.
